# hotel-insights-dashboard
Interactive Power BI dashboard for analyzing hotel revenue, occupancy, ADR, RevPAR, realization, and booking trends using Power BI, DAX, Power Query, and data modeling.
Developed an interactive Power BI Hotel Insights Dashboard to analyze hotel performance using key metrics such as Revenue, Occupancy, ADR, RevPAR, DSRN, and Realization. The dashboard provides insights into booking trends, city-wise performance, room categories, and booking platforms, helping stakeholders make data-driven decisions.
Features
Revenue, ADR, RevPAR & Occupancy KPIs
City-wise hotel performance
Revenue by room category
Weekly performance trends
Booking platform analysis
Interactive slicers (City, Category, Room Class, Week)
